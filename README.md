# e-SIM Wali Asuh SR — Frontend

Frontend statis (HTML/CSS/JS vanila) untuk GitHub Pages. Backend: Google Apps Script (REST API JSON).

- Edit **hanya** `js/config.js` → isi `GAS_URL` dengan URL Web App berakhiran `/exec`.
- Tanpa build, tanpa dependensi. PWA: bisa dipasang ke layar utama & cangkang aplikasi tersedia offline.
- Update: `git add . && git commit -m "pesan" && git push` (Pages otomatis terbit ulang).
